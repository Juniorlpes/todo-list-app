# Todo List App

This is a Flutter project to exemplify my clean [architecture proposal](https://github.com/Juniorlpes/architecture-proposal).

Note that even if you change the branch (which has different integrations), the domain layer does not change (the presentation layer does not either).

## Getting Started

This Todo List has four branchs/version: <br />
1 - Local data storage (Offline mode) <b>[Current branch]</b> <br />
2 - With Auth option and Firestore sdk to store and access data :hourglass: <br />
3 - Data access from a API Rest :hourglass: <br />
